# 校园二手交易平台前端功能测试实践

对 `campus-trade-web` 校园二手交易平台前端进行完整功能测试，覆盖用户端认证、商品浏览、商品详情、购物车、订单流程及管理端后台等核心模块。

## 🔍 测试范围

| 模块 | 测试内容 |
|----------|--------------------------------------------------------------------------------------|
| 认证模块 | 用户/管理员登录注册、表单校验、密码确认、手机号格式、退出登录、角色鉴权 |
| 首页浏览 | 商品列表加载、分类导航、轮播图、空状态、加载失败区分、分页 |
| 商品详情 | 缩略图切换、折扣标签、收藏、加入购物车、立即购买、订单参数一致性 |
