# 校园二手交易平台前端功能测试实践

对 `campus-trade-web` 校园二手交易平台前端进行完整功能测试，覆盖用户端认证、商品浏览、购物车、订单流程及管理端后台等核心模块。

## 🔍 测试范围

| 模块 | 测试内容 |
|----------|--------------------------------------------------------------------------------------|
| 认证模块 | 用户/管理员登录注册、表单校验、密码确认、手机号格式、退出登录、角色鉴权 |
| 首页浏览 | 商品列表加载、分类导航、轮播图、空状态、加载失败区分、分页 |
| 商品详情 | 缩略图切换、折扣标签、收藏、加入购物车、立即购买、订单参数一致性 |
| 购物车 | 全选、改数量、删除单个、删除选中、批量结算、事务回滚、防抖 |
| 收藏管理 | 收藏列表、取消收藏、空状态、二次确认 |
| 发布商品 | 表单校验、图片上传、格式限制、原价现价逻辑、token响应式 |
| 订单管理 | 列表加载、Tab筛选、订单详情、详情入口、分页 |
| 收货地址 | 增删改查、手机号校验、默认地址唯一性、标题正确性 |
| 个人中心 | 信息保存、表单校验、侧边栏导航、菜单高亮 |
| 管理端 | 仪表盘数据、用户/商品/订单/分类/日志管理、CRUD错误处理、侧边导航 |
| 路由鉴权 | 登录拦截、管理端鉴权、404重定向、token伪造、localStorage篡改 |
