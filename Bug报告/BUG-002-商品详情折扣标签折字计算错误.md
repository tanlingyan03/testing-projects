BUG-003: 商品详情折扣标签折字计算错误
基本信息
项目    内容
缺陷编号    BUG-013
优先级    P1 - 中
严重程度    Critical
所属模块    商品详情 / ProductDetailView
发现时间    2025-09-17
测试环境    Chrome 120 / Windows 11 / 网络正常
测试账号    zhangsan / 123456
复现步骤
1. 访问一个原价100元、现价80元的商品详情页
2. 查看折扣标签

预期结果
应显示"8折"（中文折表示应付比例）或"20% OFF"
实际结果
显示"20折"。Math.round((1 - 80/100)*100) = 20，计算的是优惠百分比却标注"折"，语义错误。ProductCard.vue 同位置标注"%OFF"才是对的
