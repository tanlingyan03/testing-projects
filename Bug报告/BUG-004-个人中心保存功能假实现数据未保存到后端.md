BUG-004: 个人中心保存功能假实现数据未保存到后端
基本信息
项目    内容
缺陷编号    BUG-004
优先级    P0 - 高
严重程度    Blocker
所属模块    个人中心 / ProfileView
发现时间    2026-07-31
测试环境    Chrome 120+ / Windows 11 / 网络正常
测试账号    testuser / ***
复现步骤
1. 用户登录后访问 http://localhost:5173/profile
2. 修改手机号、昵称、邮箱等信息
3. 点击"保存"按钮
4. 刷新页面

预期结果
保存后应调用后端API更新用户信息，刷新页面后数据保持修改后的值
实际结果
点击保存后弹出"保存成功"提示，但 saveProfile 方法没有调用任何API，数据未实际保存到后端。刷新页面后所有修改全部丢失，恢复为原始数据
